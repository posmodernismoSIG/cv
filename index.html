ArcGIS Enterprise Integration

My backend systems treat ArcGIS Enterprise as an active geospatial engine — not just a map viewer. It executes analysis, manages spatial layers, runs geoprocessing services, and stores raster datasets, all orchestrated through Python backends.

I design Python middleware APIs (Django DRF, FastAPI, Flask) that sit between client apps and ArcGIS Enterprise, handling authentication, request routing, spatial validation, and response normalization so frontends stay ESRI-agnostic.

Python is the integration language throughout: arcpy for deep ArcGIS Pro automation, arcgis SDK for REST-based portal and layer access, and Pydantic for strict spatial input contracts. All async workers run on AWS EKS / Kubernetes keeping synchronous endpoints fast.

⬡Server IntegrationArcGIS Server · Portal

Integrating ArcGIS Enterprise with Python backends starts with connecting to Portal for ArcGIS and ArcGIS Server through its REST API surface. I use token-based authentication (built-in or IWA), manage service registration, and orchestrate publishing of map, feature, and geoprocessing services programmatically — eliminating manual ArcGIS Manager steps from CI/CD pipelines.

pythonarcgis SDK · portal auth
# Connect to ArcGIS Enterprise portal
from arcgis.gis import GIS

gis = GIS(
    url="https://arcgis.myorg.co/portal",
    username=settings.ARCGIS_USER,
    password=settings.ARCGIS_PASS,
    verify_cert=True
)
# Search and access a published feature service
item = gis.content.search(
    "title:deforestation_2024 AND type:Feature Service",
    max_items=1
)[0]
flayer = item.layers[0]  # FeatureLayer
⬡Server-Side Library SetupConda · ArcPy · Python

ArcGIS Enterprise ships with its own Python environment managed by Conda. I configure server-side environments by cloning the default arcgispro-py3 environment, installing geospatial dependencies, and registering the environment with ArcGIS Server so geoprocessing scripts execute with full library access — including arcpy, GDAL, Rasterio, FastAPI, and custom packages.

bashconda · arcgis server env registration
# Clone default env, install geospatial deps
conda create --name geoenv --clone arcgispro-py3
conda activate geoenv

pip install rasterio gdal shapely geopandas
pip install arcgis==2.3.0 pydantic fastapi celery

# Register env with ArcGIS Server (Windows Server)
cd C:\ArcGIS\Server\tools\PythonEnvManagement
python RegisterPythonEnv.py \
  --env C:\conda\envs\geoenv \
  --serverUrl https://arcgis-server.myorg.co \
  --username siteadmin
⬡ArcGIS Data StoreRelational · Raster · Cloud S3

ArcGIS Data Store provides three registered store types I use in production. The Relational Data Store (PostgreSQL-based) backs hosted feature layers. The Raster Data Store caches imagery tiles for image services. The Cloud Data Store (AWS S3) holds large-volume raster collections from Prisma and ABACO pipelines without saturating server disk. I manage registration, backup, and failover on all deployments.

pythonregister S3 cloud data store via SDK
from arcgis.gis import GIS

gis = GIS("https://portal.myorg.co", "admin", pwd)

# Register S3 bucket as cloud data store
ds_config = {
    "type": "cloudStore",
    "info": {
        "objectStore": "s3://procalculo-imagery",
        "provider": "amazon",
        "region": "us-east-1",
        "credentialType": "IAMRole"
    }
}
gis.datastores.add(ds_config, name="S3ImageryStore")
⬡Push Data via REST APIapplyEdits · Feature Service

I push spatial analysis results and satellite detections directly into ArcGIS Enterprise hosted feature layers using the applyEdits REST endpoint. This keeps ABACO deforestation polygons and Prisma detection footprints live and queryable inside the Portal without manual imports. The Django backend batches edits, handles geometry serialization to ESRI JSON, and manages token refresh during long batch operations.

pythonapplyEdits · REST endpoint · batch push
import requests, json

token = requests.post(
    "https://arcgis.myorg.co/portal/sharing/rest/generateToken",
    data={"username": user, "password": pwd,
          "client": "referer", "f": "json"}
).json()["token"]

result = requests.post(
    "https://arcgis.myorg.co/server/rest/services/"
    "ABACO/FeatureServer/0/applyEdits",
    data={
        "adds": json.dumps([{
            "geometry": {"rings": rings,
                           "spatialReference": {"wkid": 4326}},
            "attributes": {"area_ha": area,
                            "confidence": score,
                            "source": "ABACO-v3"}
        }]),
        "token": token, "f": "json"
    }

⬡arcgis SDK for PythonFeatureLayer · SeDF · Portal

The arcgis Python SDK provides a high-level object model over the ArcGIS REST API. I use it for querying feature layers into Spatially Enabled DataFrames (GeoPandas-compatible), publishing analysis results as new hosted layers, invoking geoprocessing services asynchronously, and managing portal content programmatically. Integrates cleanly into Django management commands and Celery tasks for scheduled sync pipelines.

pythonarcgis SDK · FeatureLayer · SeDF · publish
from arcgis.gis import GIS
from arcgis.features import FeatureLayer
from arcgis.geometry import filters

gis = GIS("https://portal.myorg.co", token=token)
layer = FeatureLayer("https://...server/rest/.../0", gis=gis)

sdf = layer.query(
    where="area_ha > 10 AND confidence >= 0.85",
    geometry_filter=filters.intersects(aoi_geom),
    return_geometry=True, as_df=True
)
result_sdf = run_analysis_pipeline(sdf)
result_sdf.spatial.to_featurelayer(
    title="ABACO_Results_2024",
    gis=gis, folder="analysis_outputs"
)
⬡ArcPy Server AutomationGeoprocessing · Raster · Change Detection

For operations requiring deep ArcGIS Pro capabilities — multi-temporal change detection, model publishing, toolbox execution — I use arcpy in server-side scripts registered as ArcGIS Geoprocessing Services. These run on the ArcGIS Server environment, consume imagery from the Data Store, and write outputs to registered geodatabases. The Django backend triggers them via GP REST calls with async job polling.

pythonarcpy · NDVI change detection · RasterToPolygon
import arcpy

arcpy.env.workspace = r"\\datastore\imagery\abaco"
arcpy.env.overwriteOutput = True
before = arcpy.Raster("sentinel_2023_q1.tif")
after  = arcpy.Raster("sentinel_2024_q1.tif")

# NDVI = (NIR - RED) / (NIR + RED)
ndvi_b = (before.getBand(4) - before.getBand(3)) / \
         (before.getBand(4) + before.getBand(3))
ndvi_a = (after.getBand(4) - after.getBand(3)) / \
         (after.getBand(4) + after.getBand(3))
delta = ndvi_a - ndvi_b

loss = arcpy.sa.Con(delta < -0.15, 1)
arcpy.conversion.RasterToPolygon(
    loss, "deforestation_output.shp", simplify=True
)
arcpy.AddMessage("Change detection complete")
